## 2. 公司简介

青禾家居是一家围绕日常居住场景展开产品研发与品牌运营的家居生活品牌。公司成立于 2019 年，总部位于杭州，核心服务对象为城市家庭用户、年轻租住人群、新居布置客户以及企业采购客户。品牌围绕卧室、客厅、厨房、收纳四大高频空间进行产品布局，以“舒适、实用、耐看、易用”为产品原则，持续推出具备设计感与价格效率的家居产品。

与以高溢价装饰性产品为主的品牌不同，青禾家居更重视日常生活中最常被使用、最容易影响居住体验的基础类商品。例如枕具、照明、收纳与厨房整理用品，这些产品不一定最显眼，但能直接影响用户对家的感受。青禾家居的产品开发逻辑正是从这些真实、高频、可被快速感知的需求出发，帮助消费者以更低门槛完成居住空间升级。

在经营方式上，青禾家居采用“自有品牌运营 + 深度供应链协同”的模式。一方面，公司建立统一的品牌、选品、定价、视觉与服务标准；另一方面，与成熟制造端建立长期合作关系，通过滚动备货、稳定款长期生产和多仓履约体系保障品质与交付效率。品牌既服务个人消费者，也服务需要标准化采购和正式商务流程的企业客户，形成零售与企业采购并行的双通路结构。

## 3. 品牌定位与核心理念

### 3.1 品牌定位

青禾家居定位为高性价比家居生活品牌，强调“把钱花在日常真正能感知到的改善上”。品牌不是单纯追求低价，也不是走高端定制路线，而是在品质、功能、审美和价格之间寻找更适合大众家庭的平衡点。

### 3.2 品牌主张

把家的舒适，装进每一个日常细节。

### 3.3 品牌使命

通过成熟的产品方案、稳定的交付体系和友好的服务政策，让更多消费者能够以合理预算完成生活空间的舒适升级。

### 3.4 品牌愿景

成为值得长期信赖的国民家居生活品牌，在基础家居消费领域建立稳定复购、清晰口碑和长期品牌认知。

### 3.5 品牌价值观

- 舒适不是奢侈，是日常生活的基本感受。
- 实用不意味着粗糙，基础款也应该耐看、好用、好维护。
- 家居消费不应过度复杂，客户应当用更少的时间完成更明确的选择。
- 品质与价格效率可以并存，关键在于是否尊重产品本身与供应链逻辑。

### 3.6 品牌关键词

## 4. 品牌发展历程

### 2019 年：品牌成立

青禾家居生活（杭州）有限公司在杭州成立，品牌从睡眠家居与收纳整理两大类目切入，以基础高频产品为起点，建立第一批供应链合作关系。

### 2020 年：基础款产品稳定化

围绕枕具、床品、收纳柜等常用商品打磨标准款，建立以家庭场景为中心的产品评审方法，逐步形成“稳定款 + 小步迭代”的产品策略。

### 2021 年：照明与厨房类目扩展

在既有卧室与收纳场景的基础上，拓展居家照明与厨房整理产品，开始从单一产品销售转向更完整的空间型家居解决方案。

### 2023 年：多仓履约网络建立

完成杭州、佛山、武汉、成都四地仓配布局，提升不同区域订单的发货效率，减少跨区域调拨带来的时效波动。

### 2025 年：企业采购体系升级

设立企业采购顾问机制，完善报价、合同、对公付款、发票开具与分批交付流程，形成适用于项目型采购和长期补货的企业服务模型。

### 2026 年：会员体系优化

围绕新客、复购客户与高频家庭客户建立更清晰的会员权益层级，提升品牌长期留存和复购效率。

## 5. 客户画像与适用人群

### 5.1 城市家庭用户

这类客户是品牌的核心消费群体，通常关注卧室、客厅、餐边与收纳空间的日常改善，偏好实用、耐看、容易搭配且不容易出错的产品。

### 5.2 年轻租住人群

租房用户对可移动、易安装、易收纳、搬迁友好的产品需求明显更高。青禾家居的收纳与照明产品较适合这类人群，他们希望以较低成本提升生活舒适度，但又不希望投入过高装修成本。

### 5.3 新婚与新居布置人群

这类用户往往需要在有限预算内完成一整套卧室、客厅、照明和收纳的基础配置，更关注产品之间是否容易搭配、是否能一步到位。

### 5.4 品质升级型消费者

这类客户通常已有基础家居用品，但希望通过更好的睡眠体验、更合理的收纳、更舒适的照明来完成局部生活升级。

### 5.5 企业采购客户

包括办公室、员工宿舍、公寓项目、样板间、小型酒店、民宿、接待空间、电商仓配休息区等。企业客户更关注报价效率、交付稳定性、对公流程、票据支持与后续补货能力。

## 8. 产品开发与设计方法

### 8.1 高频需求优先

青禾家居优先做用户每天都会接触、最容易感知到变化的产品，比如枕具、灯具和收纳类商品。这些商品往往是居住体验改善中投入小、反馈快、复购率高的品类。

### 8.2 场景导向开发

品牌的产品开发不是围绕孤立 SKU 展开，而是从卧室、客厅、厨房和收纳等完整空间出发，考虑搭配、动线、尺寸适配、收纳效率与视觉协调。

### 8.3 稳定款优先策略

相比追求大量快速上新，青禾家居更强调稳定款和常销款的长期优化。通过控制 SKU 数量、提高单款打磨深度，建立更稳定的供货、质控与售后体系。

### 8.4 易用优先

品牌在产品立项时重点考虑以下问题：

- 是否容易安装
- 是否容易清洁
- 是否容易融入常见居住空间
- 是否适合大多数家庭日常使用习惯
- 是否能在预算内带来明确体验提升

### 8.5 风格方向

品牌整体视觉和产品风格偏向自然、简洁、轻暖调，不追求极端个性，而是强调好搭配、不过时、适合长期使用。

- 纺织类商品已水洗且无质量问题
- 因安装或使用不当造成的人为损坏
- 因超载、浸水、高温等不当使用造成的损坏

### 23.5 破损、缺件与错件处理

- 收到商品 48 小时内发现破损、缺件、错件，可优先登记补件或换件
- 结构类产品优先采用补件处理，以减少客户等待整单换货的时间
- 易碎类商品如照明和锅具，需提供外箱与商品受损照片

### 23.6 质保范围与免责边界

| 类型 | 支持范围 | 不包含情形 |
| --- | --- | --- |
| 灯具类 | 非人为电源与调光故障 | 跌落、浸水、暴力损坏 |
| 收纳结构类 | 非人为结构连接异常 | 超载、私自改装、安装错误 |
| 睡眠纺织类 | 到货瑕疵与明显质量异常 | 正常使用损耗、个人偏好问题 |
| 厨房家居类 | 到货破损与显著制造问题 | 干烧、磕碰、长期浸水使用不当 |

## 24. 企业采购执行规则

本章节用于补足企业采购中的执行细节，便于销售顾问、采购经理和项目客户快速判断是否适配合作。

### 24.1 询价前需准备的信息

企业客户在提交询价时，建议至少提供以下信息：

- 公司名称
- 项目类型
- 收货城市
- 预计数量
- 预算范围
- 期望交付时间
- 是否需要样品
- 是否需要开专票
- 是否需要分批交付

### 24.2 报价单内容标准

企业报价单通常包含以下字段：

- SKU 编号
- 产品名称
- 规格与颜色
- 数量
- 含税/未税单价
- 交付方式
- 交付周期
- 发票类型
- 报价有效期
- 备注说明

### 24.3 报价有效期

- 常规标准 SKU 报价有效期为 7 个自然日
- 涉及临时调价或促销库存的项目报价，以当期商务确认结果为准
- 涉及包装定制或分批交付的项目报价，以项目清单最终版为准

### 24.4 样品政策

| 场景 | 样品规则 |
| --- | --- |
| 常规零售 SKU | 可按样品价购买 |
| 单项目样品 1-3 件 | 订单金额达约定门槛后可抵扣部分样品费用 |
| 大批量项目打样 | 以实际打样成本核算 |
| 已下样品单 | 不作为正式大货锁单依据，需再次确认库存与排期 |

### 24.5 交付周期参考

| 订单类型 | 参考周期 |
| --- | --- |
| 标准现货小批量 | 3-7 个工作日 |
| 标准现货中批量 | 7-15 个工作日 |
| 跨仓调拨项目 | 10-18 个工作日 |
| 定制包装项目 | 15-25 个工作日 |

### 24.6 分批交付规则

- 支持按楼栋、房间批次、城市和时间节点拆分交付
- 分批交付的运费、入仓要求和签收责任以合同约定为准
- 需由客户提前确认每一批次收货联系人和收货时间窗

### 24.7 验收标准

企业项目验收通常按以下原则执行：

- 外箱数量与装箱清单一致
- SKU、规格、颜色与确认清单一致
- 明显破损、缺件、错件可在签收后 48 小时内提出
- 使用后质量问题按对应品类质保政策处理

### 24.8 补货机制

- 常销 SKU 支持项目后续补货
- 补货价格以补货时点商务确认结果为准
- 同项目长期补货可建立客户专属补货清单
- 重点项目支持预留部分安全库存

### 24.9 对账与结算

- 支持合同制采购
- 支持对公转账结算
- 发票开具信息需在付款前确认完整
- 分批项目可按节点执行对账

### 24.10 项目售后机制

- 项目客户设专属商务或客服对接窗口
- 缺件补件优先处理
- 结构类与灯具类问题优先换件，不必整单退回
- 大批量问题可建立批次复核机制
